Welcome to NeuralScratch 🧠

Snap blocks together to build, train and play with neural networks — and watch the 3D brain light up while it thinks.

  1. Pick data in the 📦 Data tab: demo sets (XOR, spirals, shapes, tones, moods, text) or import your own images, audio, text and CSV tables. You can even draw or record samples.
  2. Shape the network in 🧱 Network (or with blocks): add layers, choose activations, learning rate, optimizer.
  3. Press ▶ Train (or build a script and press ▶ Run). Cyan/magenta lines are positive/negative weights, glowing neurons are active, bright dots are signals flowing forward and orange dots are gradients flowing backward.
  4. Test it live in 🎮 Play: draw digits/shapes, type text, talk into your mic, or probe a decision map.

Blocks: Events, Data, Network, Train, Control (repeat / forever / if / if-else / for / wait until…), Math, Logic, Variables, Text, Sensing (loss, accuracy, predictions, weights…) and Output (say, tones, camera & visual effects). Use Examples in the header to load ready-made scripts.

Tips: shift-drag moves one block out of a stack · right-click deletes · the little ▶ on a stack runs only that stack · “when each epoch ends” hooks run during training.
