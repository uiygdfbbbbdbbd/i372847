Open the game menu
in a clean tab.

Three methods, one menu. Each opens the games page in a sandboxed context — about:blank, data:, or blob:. Pick whichever works on your network.

How it works

The button on this page fetches the game menu, then hands the HTML directly to a new tab in one of three ways. The tab's address bar never shows the source host — it shows about:blank, a data: URI, or a blob: URL — so URL-based filters and content blockers can't match on it.

about:blank

Opens a blank tab, uses document.write() to inject the menu HTML. Address bar reads about:blank.

data:

Encodes the entire menu as a data:text/html URL. Some browsers restrict this at the top level.

blob:

Creates a Blob and gets an object URL tied to this origin. Reliable across most modern browsers.

Add a game

Drop a name.html file in the repo. The menu auto-detects it via the GitHub API — no code changes needed.

About

A self-hosted, no-database directory of standalone HTML games. Each game is a single self-contained file — no CDNs, no trackers, no accounts. Files live in a public GitHub repo and are served through GitHub Pages.
